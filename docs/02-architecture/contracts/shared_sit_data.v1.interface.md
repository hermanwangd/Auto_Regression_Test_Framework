# C17 StageA frozen interface and semantic key v1

Input contract: shared-sit-data.v1, strict raw UTF-8 JSON <=64KiB, nesting<=16, duplicate/unknown keys rejected;32resources/32preconditions/16SUT expectations. Closed mirrored JSON Schema pins the exact metadata fields. No self-hash or input idempotency_key field is allowed. Contract metadata is externally pinned control input, not inferred admitted product source: decision contractOriginState is always UNBOUND. Referenced full artifact IDs/SHA/roles must join actual RunnerBundleService.SourceBindings.

API: assess(byte[] contract, String externalContractSHA, SourceBindings actualSource, byte[] controller, String externalControllerSHA, SitReadinessReport observations, byte[] canonicalBytes). Pure library, no file/network/JDBC/process/provider/token operation. Additive FixtureLifecycleService delegate only. Actual source object and independently pinned controller bytes join; controller source_binding_sha256 is SHA of canonical actual source.metadata(). Controller approved_contract_sha256 must equal actual externally pinned raw contract SHA. A computed matching pin does not establish who supplied it; caller provisioning remains independent.

Controller v1 exact fields: context_version=shared-sit-data-controller.v1; scope=CONTRACT/ISOLATED_ONLY/SHARED; run_id; run_namespace; source_binding_sha256; approved_contract_sha256; readiness_sha256; valid_until; ownership=UNKNOWN/LOCAL_FAKE/READY; cleanup=NOT_RUN/CONFIRMED/UNKNOWN; owner_token_refs; actual_sut_revisions [{sut_id,observed_revision,observation_ref}]; canonical_identity {sha256,run_id,suite_id,profile,batch_id}. Caller READY is normalized to UNKNOWN and can never bind persistent ownership. valid_until must be current and bounded, typed readiness must be fresh/bounded/pinned. Check IDs/kinds/purposes/expected versions and actual data/schema/SUT versions must agree. Logical owner-ref:// handles are matched only, never resolved or emitted as token values.

Decision enums: ContractState VALID/INVALID; Scope CONTRACT/ISOLATED_ONLY/SHARED_BLOCKED; Acceptance CONTRACT_ONLY/BLOCKED_INPUT/BLOCKED_PRECONDITIONS/BLOCKED_NO_SHARED_OWNERSHIP_OR_PRECLEANUP_SAVE_BINDING; OwnershipState UNKNOWN/LOCAL_FAKE; CleanupState NOT_RUN/CONFIRMED/UNKNOWN; CanonicalIdentityState MATCHED/MISSING/INVALID; OriginState UNBOUND. Readiness uses existing SitReadinessState. Canonical MATCHED means pinned bytes+identity only, not new EHS semantic acceptance. Preserve raw canonical bytes/hash/verdict, never write or invent PASS. All shared requests hard-block; persistentSharedOwnershipBound/preCleanupSaveBound alwaysfalse. Outputs only enums, static gap codes, hashes and immutable identities; no raw metadata/token/parser snippets. No production effect gate or StageB exists.

Idempotency key is returned only in decision. Version/domain: UTF-8 literal `shared-sit-data.idempotency.v1` plus LF. Then compact canonical JSON of closed object {contract,source,run}. contract is the parsed contract with resources sorted by resource_id, preconditions sorted by check_id, sut_expectations sorted by sut_id; objects recursively sorted by Java String natural order. source is {lock_sha256,composition_root_version,artifacts:[{artifact_id,sha256,source_testrepo_version,role}]} for the five referenced artifacts, sorted by artifact_id. run is {run_id,run_namespace,scope}. JSON uses ordinary UTF-8 Jackson escaping, no whitespace or trailing LF. SHA256(domain bytes || canonical JSON). No key/self SHA, random source binding UUID, readiness timestamps, canonical outcome, controller expiry or raw formatting enters the key. Raw contract/controller hashes remain separate. A semantic identity change produces a different key; an unchanged approved context rejects changed raw contract identity. This is contract idempotence, not prepared data reuse.

Source schema/raw/API expectations are frozen before behavioral RED/implementation. Canonical identity input envelope<=4MiB, controller<=64KiB, actual readiness<=32checks/32facts percheck. Fixed test clock proves freshness without runtime/SUT operations. Tests construct actual admitted public source objects in owned JUnit temporary Git fixtures; no framework Git mutation. No builds except approved compile/test; global lock supervision retained.
